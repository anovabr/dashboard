Same content in every card. Only the chrome changes. Pick one, or mix: A and D compose, B and C compose.

A · Quiet header

Controls are invisible until you hover the card, and the rare ones (rename, delete) move behind ⋯. The header keeps only what you read: name, progress, note count. Best if the four icons feel busy now.

B · Tighter rows, subsections as rails

Row padding drops from 7px to 5px and the hairline between rows goes away — the subsection gets a coloured rail instead, so the eye groups by block rather than by line. Best if your long cards (Writing, ANOVA) feel like scrolling.

C · Status you can see without reading

Each row gets a left stripe by state — red = now, amber = in progress, grey = waiting on someone else — and the coloured dot disappears. Best if you want "what is actually moving" answerable at a glance. Costs a little calm.

D · One-line summary strip

A thin strip under the title: open / this week / done this week / last touched. It answers "is this project stalling?" without opening anything — the thing a progress bar alone cannot say. Best if you care about which projects went quiet.
